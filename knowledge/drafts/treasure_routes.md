# Treasure bastion: route decision table

Every claim cites [n]. Learner edits win. See bastions.md for identification (2 ramparts, always 2 chests, big lava basin, magma-cube spawner).

## Decision variables (visible to the player)
1. **Entry point**: bridge vs ramparts vs bottom. pncakespoon's sheet lists Ninjabrain / Right Boomer as "Start: Bridge" and Top Treasure as "Start: Ramparts" [1]. HiTrippy has "Entry Points" 2:43 and "Choosing your Route" 3:51 [2]; MCSR Wiki "Entries" 6:43 [3].
2. **Lava-filled basin** (backup route needed) [2][4].
3. **Gold armour** — MCSR Wiki has a "Safe No Armor" route [3].
4. **TNT available** — TNT Treasure route [5][4].
5. **Gold pickaxe** — Metacor: "highly recommended to Craft a Gold Pickaxe with the Gold Blocks on the bridge" [6].
6. **Gravity blocks** — Top Treasure has with/without gravity-block versions [7].

## Decision table
| Situation | Route | Source |
|---|---|---|
| Default / beginner | **Safe Boomer** (HiTrippy's one recommended treasure route) | [2][8] |
| Comfortable, normal basin | **Boomer (Advanced)** / Right Boomer | [1][2][3] |
| Have TNT | **TNT Treasure** | [5][4] |
| Arrive at ramparts (top) | **Top Treasure** (gravity / no-gravity blocks) | [1][7] |
| Lava-filled basin | Lava-filled / backup route | [2][4] |
| No gold armour | Safe No Armor | [3] |
| Basic (Kanes) | Basic Treasure | [5] |

## Exceptions
- Pie-ray: treasure spawner gives a false positive like a blaze spawner; destroy the spawner and pie-ray again [6]. Kanes "Break Spawner quickly" 7:09 [5].
- Risks: piglins hard to gather at the bottom; magma cubes (bastions.md [7]).
